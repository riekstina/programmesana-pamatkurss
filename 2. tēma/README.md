str -> string jeb simbolu virkne. Skaitlis tiek rakstīt pēdiņās, tas apzīmē tekstuālo informāciju.
int -> integer jeb vesels skaitlis. Izmantots, kad tiek rakstītas matemātisks skaitlis bez komatiem jeb vesels skaitlis.
float -> floating-point number jeb daļskaitlis. Izmantots, kad tiek rakstīts skaitlis ar decimāldaļām.
