- pirmais, kur tika ievadīts a = "5" ir str. str -> string jeb simbolu virkne. Skaitlis tiek rakstīt pēdiņās, tas apzīmē tekstuālo informāciju.
- otrais, kur tika ievadīts b = 5 ir int. int -> integer jeb vesels skaitlis. Izmantots, kad tiek rakstītas matemātisks skaitlis bez komatiem jeb vesels skaitlis.
- trešais, kur tika ievadīts c = 5.5 ir float. float -> floating-point number jeb daļskaitlis. Izmantots, kad tiek rakstīts skaitlis ar decimāldaļām.



- print(17 / 5) rezultāts sanāca 3,4 (sanāk precīzs rezultāts)
- print(17 // 5) rezultāts sanāca 3 (rezultāts sanāk 3, jo 17 dalot ar 5, tajā ietilpst piecinieks veselas trīs reizes)
- print(17 % 5) rezultāts sanāca 2 (rezultāts sanāca 2, jo 17 dalot ar 5, piecinieki ietilpst trīs veseli un pāri paliek 2)
- print(2 ** 3) rezultāts sanāca 8 (rezultāts sanāca 8, jo 2 reizināts ar sevi 3 reizes ir 8)

- papilduzdevumā ierakstot līmeni 2,5 rezultāts sanāca 6,25 ; bet ierakstot līmeni 10, rezultāts sanāca 100
- spēks pieaug 4 reizes, ja līmenis pieaug 2 reizes
